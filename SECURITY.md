# Security policy

Please do not open a public issue for a vulnerability.

Use GitHub's private vulnerability reporting flow:

<https://github.com/zhom/gitdebt/security/advisories/new>

Include the affected route or component, reproduction steps, impact, and any
suggested mitigation. The maintainer will acknowledge a complete report as
soon as practical. There is no paid bug-bounty program.

Supported code is the latest version on `main` and the currently deployed
`gitdebt.com` / `api.gitdebt.com` services.
