## Features

- Star history for one repo or up to eight overlaid repos: calendar and aligned
  timelines, date windows, log scale, CSV/JSON export.
- Repository-health charts from git history: bug magnets, churn, contributors,
  commit heatmaps, TODO/FIXME trend, bus factor, commit volume, language lines.
- Package downloads (npm, crates.io, PyPI, Docker) plotted against stars.
- Embeddable README assets: static SVG and animated GIF charts, repo and
  profile cards, badges, PNG/WebP variants.
- gitdebt stores star timestamps, not stargazer profiles, and does not score,
  label, or judge accounts.

> [!NOTE]
> New star history comes from GH Archive, which records public star events but
> not unstars, so archive-backed curves are approximate public star activity.
> Repositories cached from GitHub earlier keep their exact snapshots.

## Usage

Open [gitdebt.com](https://gitdebt.com) and enter `owner/repo`, or use the
live report route directly: `https://gitdebt.com/report?repo=facebook/react`.

To embed a static chart that follows the reader's theme:

```html
<a href="https://gitdebt.com/owner/repo?ref=readme">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="https://api.gitdebt.com/api/repos/owner/repo/chart.svg?theme=dark">
    <source media="(prefers-color-scheme: light)" srcset="https://api.gitdebt.com/api/repos/owner/repo/chart.svg?theme=light">
    <img alt="Star history of owner/repo" src="https://api.gitdebt.com/api/repos/owner/repo/chart.svg?theme=dark">
  </picture>
</a>
```

Or the animated GIF variant, which loops a wave animation by default:

```html
<a href="https://gitdebt.com/owner/repo?ref=readme">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="https://api.gitdebt.com/api/repos/owner/repo/chart.gif?theme=dark">
    <source media="(prefers-color-scheme: light)" srcset="https://api.gitdebt.com/api/repos/owner/repo/chart.gif?theme=light">
    <img alt="Animated star history of owner/repo" src="https://api.gitdebt.com/api/repos/owner/repo/chart.gif?theme=dark">
  </picture>
</a>
```

## Browser extension

`extension/` is a zero-build Manifest V3 extension for Chromium and Firefox
that shows the same report on public GitHub repository pages. It has no login,
telemetry SDK, or remote code. See [extension/README.md](extension/README.md).

The stack: Rust/Axum/Postgres backend, static Astro 7 + React frontend, plain
MV3 JavaScript extension.

## Development

```bash
scripts/db.sh up

export DATABASE_URL=postgres://gitdebt:gitdebt@localhost:5432/gitdebt
export GITHUB_TOKEN=ghp_...
cargo run -p backend --bin gitdebt-api

# second shell (same env): drains the ingestion and analysis queues
cargo run -p backend --bin gitdebt-worker

# third shell
pnpm install
PUBLIC_API_BASE=http://localhost:8787 pnpm --filter gitdebt-frontend dev
```

Configuration lives in [backend/.env.example](backend/.env.example). See
[CONTRIBUTING.md](CONTRIBUTING.md) for setup details, quality checks, and
project rules, and [SECURITY.md](SECURITY.md) for reporting vulnerabilities.
